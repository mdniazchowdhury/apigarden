# APIGarden v1.7.1

- Website Voice API now always shows **Run API**, **Save API**, and **Download JSON** after analysis.
- Save API works before or after a run. A pre-run save is stored as a draft; a successful run adds the live outcome.
- Download JSON works before a run (draft JSON) and after a run (live outcome JSON).
- Faster Run API path: shorter page-ready wait, shorter content-script retry delays, and a shorter website bridge timeout.
- Saved website Voice APIs can also download draft JSON before their first successful run.
- Extension version bumped to 1.7.1.
