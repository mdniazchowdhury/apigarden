# APIGarden v1.7.0

- Added the same Create API by Voice workflow to the website.
- Website voice recording continues until Stop Recording is pressed.
- Website can use the installed extension as a bridge to open/filter real sites and capture live JSON.
- Added automatic best-site selection when the user says “any website”, “best website”, or gives no site.
- Category routing: footwear → Bata, books → Rokomari, electronics → Pickaboo, appliances → Walton, general products → Daraz.
- Improved browser/tab reliability with content-script reinjection and retry logic for dynamic websites.
- Voice JSON now records whether the website was auto-selected.
